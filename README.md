#Istanbul Retail Customer Data Analysis

## Project overview
This project analyzes retail transactions from 10 Istanbul shopping malls between 2021 and 2023. It compares transactions, products sold, and revenue by gender, age group, product category, and payment method.

## Project files
- Analysis report
- PowerPoint presentation
- Power BI report
- Chart screenshots
- SQL summary queries

## Method
Revenue was calculated as quantity multiplied by unit price. The analysis uses summary comparisons; it does not use a prediction model.

## Key findings
- The dataset contains 99,457 transactions and 298,712 products sold.
- Total revenue is TL 251,505,794.25.
- Female customers account for 59.81% of transactions.
- The 31–50 age group has the highest revenue: TL 97,150,259.90.
- Clothing is the highest-revenue category.
- Cash is the most-used payment method; average transaction values are similar across payment methods.

## Limitation
The dataset does not include product costs, so profit and profit margin cannot be calculated.
